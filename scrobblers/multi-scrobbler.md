# 📊 multi-scrobbler

multi-scrobbler is a self-hosted application that collects listening activity from multiple sources and forwards scrobbles to multiple clients.

## ⭐ Features

- **Type:** Scrobbling aggregator and router
- **License:** MIT
- **Open Source:** ✅ Yes
- **Price:** 🆓 Free
- **Deployment:** Docker or Node.js
- **Highlights:**
  - Supports sources such as Navidrome, Jellyfin, Plex, Spotify, YouTube Music, Koito, and desktop players
  - Supports clients such as Koito, Last.fm, ListenBrainz, Libre.fm, and Maloja
  - Web interface with status, statistics, logs, and runtime controls
  - Queues and retries scrobbles when a service is temporarily unavailable
  - Supports Docker images for x86 and ARM

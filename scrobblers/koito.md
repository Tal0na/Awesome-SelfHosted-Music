# 📊 Koito

Koito is a modern, themeable, self-hosted scrobbler and listening history dashboard.
It accepts submissions through a custom ListenBrainz-compatible endpoint and stores the listening data on your own server.

## ⭐ Features

- **Type:** Self-hosted scrobbler and listening history dashboard
- **License:** MIT
- **Open Source:** ✅ Yes
- **Price:** 🆓 Free
- **Deployment:** Docker or native installation
- **Highlights:**
  - Themeable web interface
  - ListenBrainz-compatible submission endpoint
  - Listening history and statistics under your control
  - Works with clients that support custom ListenBrainz URLs

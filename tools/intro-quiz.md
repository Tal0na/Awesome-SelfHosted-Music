# 🎵 Intro Quiz

Intro Quiz is a self-hosted "guess the intro" music quiz for family game nights, built around a Navidrome library.

The app plays the first five seconds of a song while players race to identify it on their phones. The fastest correct answer scores the most points.

## ⭐ Features

- **Source:** Navidrome via the Subsonic API
- **License:** MIT
- **Open Source:** ✅ Yes
- **Deployment:** Docker
- **Requirements:** Navidrome, Docker, Last.fm API key, and a cast display, Android TV, or cast speaker
- **Display:** Cast display or Android TV with scoreboard, album art, and audio
- **Audio-only mode:** Use a cast speaker through Home Assistant and Music Assistant while phones handle the questions
- **Highlights:**
  - Local gameplay on your own network
  - Uses short streamed clips without modifying the music library
  - Dedicated non-admin Navidrome account
  - Read-only access to music files, tags, playlists, and play counts
  - Docker image available for self-hosted deployment

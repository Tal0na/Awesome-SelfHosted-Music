# 🎨 Make-a-Wrapped

Make-a-Wrapped is an open-source tool for generating Spotify-like listening summary posters from self-hosted music and scrobbling services.

It can generate a wrapped for a selected period, including top artists, tracks, listening time, genres, and artwork.

## ⭐ Features

- **Sources:** ListenBrainz, Last.fm, Libre.fm, and Navidrome
- **License:** AGPL-3.0
- **Open Source:** ✅ Yes
- **Deployment:** Public web app or self-hosted installation
- **Highlights:**
  - Generate reports for a month, year, or custom period
  - Shareable poster-style output
  - Customizable templates
  - Optional artwork upload and artwork positioning
  - Designed as a community alternative to Spotify Wrapped

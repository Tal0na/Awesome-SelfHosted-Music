# 🌐 Local Music Players for Web Browsers

Browser-based players that can play local audio files without requiring Navidrome or another music server.

## ⭐ Recommended Player

### Webamp

Webamp is an open-source Winamp reimplementation built with HTML5 and JavaScript.
It runs in modern browsers and can be used to play local audio files through a familiar playlist interface.

- **Platform:** Modern browsers
- **License:** MIT
- **Open Source:** ✅ Yes
- **Price:** 🆓 Free
- **Status:** 🟢 Actively maintained
- **Highlights:**
  - Runs directly in the browser
  - Winamp-style playlist and interface
  - Custom skin support
  - Can be embedded into other websites
  - No server installation required for local playback

#### 🔗 Links

- [Web app](https://webamp.org/)
- [GitHub repository](https://github.com/captbaritone/webamp)

## ⚠️ Notes

- Browser support for local files depends on the browser's file access permissions.
- For web clients connected to a Navidrome or Jellyfin server, see the [server web clients](../Servers-Clients/web.md).

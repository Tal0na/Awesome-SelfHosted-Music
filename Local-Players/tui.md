# 🎧 Local CLI / TUI Music Players

Terminal-based music players for libraries stored on the local machine.

## ⭐ Recommended Players

### cmus

- **Platform:** Linux / macOS / BSD / Unix-like systems
- **License:** GPL-2.0
- **Open Source:** ✅ Yes
- **Price:** 🆓 Free
- **Status:** 🟢 Actively maintained
- **Highlights:**
  - Fast ncurses interface
  - Library and playlist management
  - Gapless playback and ReplayGain support
  - Support for many audio formats through optional input plugins
  - Keyboard-driven workflow

#### 📥 Installation

- [GitHub repository](https://github.com/cmus/cmus)
- [Official website](https://cmus.github.io/)

---

### musikcube

- **Platform:** Linux / macOS / Windows / Raspberry Pi
- **License:** BSD-3-Clause
- **Open Source:** ✅ Yes
- **Price:** 🆓 Free
- **Status:** 🟢 Actively maintained
- **Highlights:**
  - Cross-platform terminal interface
  - Local library indexing and playback
  - Keyboard shortcuts and configurable navigation
  - Optional streaming server and remote-control support
  - Suitable for desktop systems and Raspberry Pi setups

#### 📥 Installation

- [GitHub repository](https://github.com/clangen/musikcube)
- [Official website](https://musikcube.com/)
- [Releases](https://github.com/clangen/musikcube/releases)

---

## ⚠️ Notes

- These players work with local files and do not require Navidrome or another music server.
- Check each project's documentation for supported codecs and platform-specific installation steps.

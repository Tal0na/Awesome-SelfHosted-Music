# 🎧 Local Music Players for iOS

Players for listening to music files stored on an iPhone or iPad, without requiring a self-hosted music server.

## ⭐ Recommended Apps

### VLC for iOS

- **License:** MPL-2.0 / GPL-2.0-or-later
- **Open Source:** ✅ Yes
- **Price:** 🆓 Free
- **Status:** 🟢 Actively maintained
- **Highlights:**
  - Plays common and less common audio formats
  - Imports files through Wi-Fi, cloud storage, and file servers
  - Supports offline playback
  - Supports SMB, SFTP, FTP, NFS, UPnP/DLNA, and network streams
  - Includes AirPlay and CarPlay support

#### 📥 Installation

- [App Store](https://apps.apple.com/app/vlc-for-mobile/id650377962)
- [Official website](https://www.videolan.org/vlc/download-ios.html)

---

### foobar2000 mobile

- **License:** Proprietary freeware
- **Open Source:** ❌ No
- **Price:** 🆓 Free
- **Status:** 🟢 Actively maintained
- **Highlights:**
  - Plays local audio files and mainstream formats
  - Supports gapless playback and ReplayGain
  - Includes tagging and library management features
  - Supports customizable playback components

#### 📥 Installation

- [Official iOS page](https://www.foobar2000.org/ios)
- [Official website](https://www.foobar2000.org/)

## ⚠️ Notes

- These apps are for local playback. For Navidrome or Jellyfin connections, see the [iOS server clients](../Servers-Clients/ios.md).
- Confirm current iOS compatibility and store availability before installing.
